# Isabella_sobre-mim
# Sobre Mim | Isabella Benini Lins

Este repositório contém uma página web desenvolvida durante as aulas de **Desenvolvimento de Sistemas**, no 1º ano do Ensino Médio Técnico da Germinare Tech, em 2026.

O projeto começou como uma atividade de apresentação pessoal utilizando HTML e, ao longo do ano, foi aprimorado com CSS, organização semântica e conceitos de responsividade.

## Sobre o projeto

A página reúne informações sobre mim, meus interesses, minha família e algumas experiências importantes da minha trajetória.

Entre os conteúdos apresentados estão:

- Apresentação pessoal e curiosidades;
- Minha família e meus cachorros;
- Músicas que gosto de ouvir;
- Lugares que já visitei e quero conhecer;
- Projeto interdisciplinar **Ceris 2026**, incluindo nosso stand, equipe e mascote Cerita.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização semântica do conteúdo.
- **CSS3:** estilização, cores, espaçamentos e organização visual.
- **Flexbox:** alinhamento das imagens e galerias.
- **Pseudoclasses:** interações nos links.
- **Google Fonts:** utilização da fonte Poppins.
- **Git e GitHub:** versionamento e organização das alterações.

## Objetivo

Aplicar os conhecimentos desenvolvidos durante as aulas e acompanhar a evolução das minhas habilidades em desenvolvimento web, transformando uma página inicial em uma interface mais organizada e visualmente agradável.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/beniniisabella/Isabella_sobre-mim.git
```

2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo `index.html` no navegador ou utilize a extensão Live Server.
